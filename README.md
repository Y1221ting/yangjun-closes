# Yelena 的衣柜

本地运行的衣柜与搭配工具（朋友版）。把自己每件衣服拍下来、抠好图导入，
在画布上自由拼出搭配，再套到自己的全身照上预览效果。

**所有数据只存在你的电脑里，不联网、不上传。**

当前版本：**v0.7.0**

> 界面和窗口标题显示为「Yelena 的衣柜」。当前在本地源码运行，暂未打包；
> 打包产物名可以按需要改成 `Yelena的衣柜.exe`。

## 功能

### 界面

- **蓝水彩夜空风**：雾蓝水彩背景 + 水面月亮，两块悬浮奶油面板，金色挂杆，
  奶白/淡蓝衣帽柜，标题用幼圆
- 侧栏顶部是「Yelena 的衣柜」贴纸 Logo，下面是衣橱目录与每类件数
- 打开程序先看到满屏等待封面（保留插画里的橙色标题），约 4 秒后淡出；
  点击任意处**立即**跳过
- 等待封面可以在「设置 → 启动体验」里关闭；开关用 cookie 记住，
  程序每次随机端口启动也不会丢
- 七只星星宝宝各有性格和专属小动作：相机=元气（闪光 + 打开添加）、
  长椅=慢悠悠（摇一摇）、精灵=猫系傲娇（歪头 + 小金星）、奶牛=憨憨（蹦高）、
  碗里=温柔（轻轻浮起 + 小金星）、飞行=好奇（绕圈）、勺子=贪吃（搅一搅）；
  台词按各自性格随机。只有相机额外打开添加衣服，其他小人只做动作和气泡。

### 衣柜

- 衣服按类别挂在衣架上：上衣、外套、下装、连衣裙
- **首页最下方是大型嵌入式衣帽柜**：
  - 左侧 4 层 × 2 格 = 8 个鞋格，每格一双鞋
  - 右上 3 个帽子格，右下 2 层 × 3 格 = 6 个包格
  - 每个格子独立奶白隔板，格背是半透明淡蓝，像玻璃后透出夜空，空位也保留
  - 空格里有一层很淡的奶油宝宝底纹（七只轮流，抽屉只露小头像），
    放入单品后自动消失
  - 每个柜区第一只可点小人会随空格挪窝：鞋=奶牛、帽=飞行、包=勺子、抽屉=碗里
  - 顶柜 3 扇奶白门，点击 3D 打开，里面是收纳盒
  - 底部 3 个抽屉，点击拉开，每个抽屉 3 个小格，共 9 格，可放小配饰
  - 柜门、分区和抽屉都带用途标签：收纳盒 1/2/3、鞋、帽子、包、小配饰 1–9
  - 柜内物品透明展示，悬停显示名称
  - 可以拖动换格；拖到已有物品的格子会交换位置
  - 物品超过基础格位时，自动在对应区域加一层
- **配饰独立收纳区**：挂杆、纸袋、平放、抽屉四种摆放方式，每件配饰可单独选择
- 配饰透明展示，不再套白色卡片，带常驻小纸标签
- 纸袋里的配饰，鼠标悬停时袋口打开，完整单品升到袋子上方
- **静止显示侧面，鼠标悬停旋转展开正面**，放大并浮起阴影
- **按住衣服左右拖动可以调整顺序**，松手自动保存
- 左侧衣橱目录按类别切换；顶部「筛选」弹层支持颜色、季节、场合；名称搜索
- 悬停显示名称、类别、颜色

### 衣服详情

- 正面 / 左前 45° / 侧面 / 左后 135° / 背面，拖动旋转查看
- 单个角度可以微调大小和位置
- 可以替换任意角度的图片

### 试衣模特

- 搭配页顶部固定展示「我的试衣模特」，五个角度可拖动旋转
- 透明模特站在奶白/淡蓝衣帽间舞台上，底部金色地板，带柔和脚底阴影
- 没有模特图时卡片收成一条小舞台，给下面的搭配列表让出空间
- 模特图存在 `data/model/`，属于个人素材，不进入 Git
- 以后每套搭配的五角度上身图会在这张卡片里切换（后续版本）

### 搭配

- 空白画布，从左侧衣柜点衣服加入
- 拖动、滚轮缩放、调整前后层次
- 上下边缘裁切：塞衣角、藏下摆
- 画布、场景标签、名称自动保存；右上角还有「保存」按钮，想手动确认时点一下
- 搭配库：真实画布预览、场景筛选、名称搜索
- 导出 1200×1600 PNG，自动打开文件夹

### 上身图

- 每套搭配可以上传 5 个角度的整套上身图
- 独立「上身展示」页：拖动旋转、逐角度微调
- 搭配库封面优先使用上身图

### 数据安全

- 删除衣服 / 搭配只是**移入回收站**，图片不会立刻删除
- 回收站可以恢复，只有「彻底删除」才真正移除图片
- 每次启动自动备份数据库，保留最近 7 份
- 设置页可以打包整个 `data` 目录做完整备份，保留最近 5 份

### 快捷键

- **1 秒内连按两次 F**：返回上一页
- 画布上 **Delete**：从搭配中移除选中的单品
- **Esc**：取消弹窗

## 首次使用

### 1. 准备衣服图片

每件衣服准备一套角度图（至少三张）：

| 角度 | 说明 |
|------|------|
| 正面 | 衣服挂起来，正对着拍 |
| 侧面 | 转 90°，从侧面拍 |
| 背面 | 转 180°，从背面拍 |
| 左前 45° | 可选，让旋转更顺 |
| 左后 135° | 可选 |

拍好后用 AI 抠图工具导出**透明背景 PNG**。

### 2. 准备整套上身图（可选）

用 AI 工具把自己的整套搭配生成多个角度的上身图，再在搭配页里上传。
每套搭配都可以单独上传正面 / 45° / 侧面 / 135° / 背面，用于「上身展示」。

### 3. 导入

打开程序 → 添加衣服 → 选择图片（也可以直接从文件夹拖入）→ 填写信息 → 保存。

类别选「配饰」时，还会出现「挂杆 / 纸袋 / 平放 / 抽屉」四个摆放方式：
围巾、腰带适合挂杆；较大的配饰适合纸袋或平放；戒指、手套等小件可以选「抽屉」，
放进衣帽柜底部的小抽屉里。帽子是独立类别，导入时直接选「帽子」，会进入衣帽柜右上角。

> 关闭添加窗口不会丢失内容，下次打开可以继续填写；整个程序关闭后草稿不保留。

## 运行（开发环境）

```bash
# 确认 Python 3.11
py -3.11 --version

# 创建虚拟环境
py -3.11 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt

# 运行
.venv/Scripts/python.exe main.py
```

> 系统默认的 `python` 是 3.8，不要直接用。

---

## 打包成 exe

先关闭正在运行的 `Yelena的衣柜.exe`：

```bash
.venv/Scripts/pyinstaller.exe --noconfirm --onefile --windowed ^
  --name=Yelena的衣柜 ^
  --icon=web/assets/icon.ico ^
  --add-data "web;web" ^
  --collect-all webview --collect-all pythonnet --collect-all clr_loader ^
  main.py
```

产物在 `dist/Yelena的衣柜.exe`。数据放在 exe 同级的 `data/` 文件夹，整个文件夹拷走就能换电脑。

## 常见问题

**Q：旋转时三张图对不齐？**
A：在衣服详情页点对应角度的「微调」，调大小和上下位置。

**Q：图片提示「没有透明背景」？**
A：回到抠图工具重新导出透明 PNG。

**Q：误删了衣服怎么办？**
A：设置 → 回收站 → 找到它 → 恢复。

**Q：换了新电脑？**
A：把整个程序文件夹（含 `data/`）拷过去，双击 exe。

**Q：数据会丢吗？**
A：程序每次启动自动备份数据库；建议再做手动完整备份。

**Q：启动等待封面看腻了，能关掉吗？**
A：可以。设置 → 启动体验 → 取消勾选「启动时显示等待封面」，下次打开直接进衣柜。
