## 阶段 0 · 环境与可运行的空窗口

### 目标
打通「Python → 本地服务 → pywebview 窗口 → 打包 exe」整条链路。
**这一步必须最先做**，因为接口库能不能打包成 exe 是全项目最大的技术风险。

### 任务

1. 在项目根目录创建虚拟环境（固定 Python 3.11）
2. 安装 `pywebview`、`Pillow`，生成 `requirements.txt`
3. 写 `main.py`：启动一个返回「hello」的本地 HTTP 服务 + 打开 pywebview 窗口
4. 写 `web/index.html`：显示一个居中的「个人衣柜」标题
5. 用 PyInstaller 打包，双击 exe 确认窗口能打开
6. 建好完整目录骨架（`app/` `web/` `data/` `logs/` `tests/`）

### 验收标准

- [ ] 命令行 `python main.py` 能弹出窗口，显示标题
- [ ] 双击打包出来的 exe 也能弹出同样的窗口
- [ ] 窗口关闭后进程正常退出（任务管理器里没有残留）
- [ ] `logs/app.log` 里有启动记录

### 风险点

> 如果 pywebview 打包失败，**立即在这里换方案**（Electron 或「启动器 + 浏览器」），
> 不要带着这个问题继续写业务代码。

## 阶段 1 · 数据层与导入第一件衣服

### 目标
衣服能被完整地存进数据库和磁盘，并且能重新读出来。

### 任务

1. `app/config.py`：路径、类别、颜色、季节枚举
2. `app/db.py`：建表、事务封装、`PRAGMA user_version` 迁移
3. `app/services/image_service.py`：裁剪透明边、统一高度、转 WebP、缩略图
4. `app/services/garment_service.py`：增删改查
5. `app/api/garments.py` + `app/server.py`：路由与 JSON 响应
6. `web/js/api.js`：前端请求封装与统一错误处理
7. 做一个**最简导入页**：三个文件选择框 + 名称/类别/颜色 + 保存按钮

### 验收标准

- [ ] 选择三张 PNG，填写名称和类别，点保存能成功
- [ ] `data/garments/<id>/` 下出现 front/side/back/thumb 四个 WebP 文件
- [ ] 原始 PNG 保留在 `original/` 下
- [ ] 关掉程序重新打开，衣服信息还在
- [ ] 上传一张没有透明背景的图，提示「这张图没有透明背景…」而不是崩溃

### 常见坑

- PNG 模式下 `getbbox()` 取的是整张图的边界，要用 alpha 通道的 bbox
- WebP 保存要显式 `save(..., "WEBP", lossless=False, quality=90)`
- 文件名统一用 garment_id，不要用用户输入的名称（有特殊字符）

## 阶段 2 · 衣柜页

### 目标
把阶段 1 存下来的衣服，全部以缩略图卡片展示出来，并且能筛选。

### 任务

1. `web/js/router.js` + 侧边栏导航
2. `web/css/wardrobe.css`：网格布局（响应式列数）
3. `wardrobe.js`：加载数据、渲染卡片、空状态
4. 顶部筛选栏：类别（分段按钮）、颜色、季节、场合、搜索框
5. 卡片 hover 效果、点击进入详情占位页
6. 分页或懒加载（每批 60 件）

### 验收标准

- [ ] 30 件衣服以网格显示，每张卡片有缩略图、名称、类别
- [ ] 点「上衣」只显示上衣；再点「黑色」只剩黑色上衣
- [ ] 搜索框输入名称，实时过滤
- [ ] 没有任何衣服时显示引导文案和「添加衣服」按钮
- [ ] 缩略图滚动时才加载（Network 面板可见）

## 阶段 3 · 三图旋转查看

### 目标
衣服详情页里，可以拖动鼠标让衣服转起来看三个面。

### 任务

1. 衣服详情页布局（左展示区 / 右信息栏）
2. `rotate-view.js`：角度状态、拖动、`requestAnimationFrame` 更新
3. 多角度帧（3~5 张，含可选的 45° / 135°）交叉淡入与轻微旋转的视觉调参
4. 双击复位；角度指示点；缺图与单图时的降级处理
5. 图片预加载与加载中骨架

### 验收标准

- [ ] 按住拖动能从正面连续看到侧面、背面
- [ ] 松手停在当前角度，不弹回
- [ ] 双击回到正面
- [ ] 转动过程中没有明显卡顿、没有白闪
- [ ] 只有正面和背面两张图时，中间段显示正面（不报错）

### 调参提示

角度映射、旋转系数、压缩比、透明度曲线这四个参数在 `rotate-view.js`
顶部集中成常量，方便反复调整。

## 阶段 4 · 搭配画布（平铺）

### 目标
这是整个项目的核心页面：把衣服拖到空白画布上拼成一套搭配并保存。

### 任务

1. 搭配编辑页三栏布局：左侧衣柜抽屉 / 中间画布 / 右侧属性
2. 画布等比缩放适配窗口（1200×1600 逻辑尺寸）
3. 拖拽单品（Pointer Events）、选中、控制条
4. 滚轮缩放（以鼠标为中心）、层次调整、删除
5. 按类别默认尺寸与默认位置
6. 防抖自动保存（800ms）到 `outfit_items`
7. 新建搭配 / 改名 / 删除搭配
8. 加载已有搭配时完整还原

### 验收标准

- [ ] 从左侧拖一件上衣到画布，出现在胸口位置
- [ ] 拖动、滚轮缩放流畅，不跟手卡顿
- [ ] 外套能盖住上衣，能一键置顶/置底
- [ ] 删除单品后画布和数据库都更新
- [ ] 关闭程序再打开，搭配的位置、大小、层次完全一致
- [ ] 同一件衣服能同时出现在多套搭配里

### 常见坑

- 缩放必须围绕鼠标位置，否则体验很差（要换算坐标）
- 拖动期间不要写数据库，松手才写
- 画布缩放后，鼠标坐标要除以缩放比才能得到逻辑坐标

## 阶段 5 · 搭配库与场景标签

### 目标
所有搭配能像衣柜一样浏览、筛选、进入编辑。

### 任务

1. 搭配库网格（封面自动生成：用画布前几件衣服拼一个缩略图，或统一占位图）
2. 场景标签选择器（多选）
3. 按场景筛选、按名称搜索
4. 新建搭配入口、重命名、删除

### 验收标准

- [ ] 搭配按保存时间排列，显示名称和场景标签
- [ ] 点「正式」只显示打了正式标签的搭配
- [ ] 新建按钮能直接进入空白画布
- [ ] 删除搭配后列表立即更新

---

## 阶段 6 · 模特与上身预览

### 目标
一套做好的搭配，能套到自己的全身照上看效果。

### 任务

1. 设置页：上传 / 替换模特照片
2. 模特头顶、脚底位置校准滑块
3. 搭配编辑页顶部「平铺 / 上身」切换
4. 首次切换到上身：按类别槽位自动摆放
5. 上身视图独立保存坐标；手动拖动后 `locked = 1`
6. 「重新自动摆放」按钮
7. 模特照片缺失时的引导

### 验收标准

- [ ] 上传一张全身照后，设置页显示预览
- [ ] 一套「上衣 + 裤子 + 鞋」切到上身，三件自动出现在正确位置
- [ ] 在模特身上拖动裤子后，切走再切回来，位置保持不变
- [ ] 平铺视图的布局不受上身调整影响
- [ ] 点「重新自动摆放」后恢复默认位置
- [ ] 没上传模特照时，提示上传而不是空白画布

### 常见坑

- 槽位是归一化坐标，不要写死像素
- `locked` 必须按 item 存，不要做成全局设置

## 阶段 7 · 导出与体验打磨

### 目标
把满意的一套搭配保存成图片，整体体验顺滑。

### 任务

1. 前端 Canvas 合成导出（含模特或白底）
2. 后端保存到 `data/exports/`，返回路径
3. 导出后提示并打开文件夹
4. 全局 toast、加载骨架、空状态文案统一
5. 键盘快捷键：Delete 删除、Esc 取消选中
6. 首次使用的引导（添加衣服 → 做搭配 → 上身）

### 验收标准

- [ ] 导出的图片与屏幕所见一致（位置、层次、大小）
- [ ] 图片含有透明背景（平铺视图）或模特照片（上身视图）
- [ ] 导出文件名包含搭配名和日期
- [ ] 所有操作都有可见反馈，没有「点了没反应」

## 阶段 8 · 打包发布

### 目标
生成一个双击即用的 exe，并验证数据可迁移。

### 任务

1. PyInstaller 打包（`--onefile --windowed`）
2. 确认 `web/` 资源正确打进包内
3. 数据目录定位在 exe 同级 `data/`
4. 在**另一台电脑或干净目录**测试
5. 写 `README.md`：怎么拍照、怎么抠图、怎么用
6. 做一份完整备份（代码 + 数据）

### 验收标准

- [ ] 把 exe 放到一个空文件夹，双击能启动
- [ ] 首次运行自动创建 `data/` 并建库
- [ ] 导入衣服 → 做搭配 → 关掉 → 重开，数据完好
- [ ] 把整个文件夹拷到另一台 Windows 电脑，双击同样能用
- [ ] 杀毒软件不误报（如有误报，记录并说明如何添加信任）

## 每日工作流

### 开始
1. 读 `开发日志/YYYY-MM-DD/待办事项.md`
2. 确认今天要完成的功能点（一次只做一个）

### 过程中
1. 先写/改代码 → 运行验证
2. 验证通过再写下一个
3. 遇到卡住超过 30 分钟的问题，先记录下来，换一个能做的小事

### 结束
1. 更新 `开发日志/YYYY-MM-DD/日志.md`：完成了什么、卡在哪、明天做什么
2. 备份项目文件夹（阶段结束时）

## 如果时间不够，优先砍什么

按优先级从后往前砍：

1. 先砍：导出图片（F11）→ 用截图代替
2. 再砍：深色/换肤、动画打磨
3. 再砍：搜索（保留分类筛选）
4. 最后才砍：上身预览（F08/F09）—— 这是差异化功能，尽量保住

**绝对不能砍**：添加衣服、衣柜浏览、搭配画布、保存搭配。
