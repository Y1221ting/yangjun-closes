## 五、朋友版需要改的地方

1. **品牌**
   - `app/config.py` → `APP_NAME`
   - `README.md` 标题与说明
   - `web/assets/yt-brand.webp`、`icon.ico`、`icon.png`
   - `web/js/welcome.js` 里的 `yt-welcome` 键
2. **本地路径**
   - `CLAUDE.md` 里的项目路径
3. **模特图（可选）**
   - 新项目没有带个人模特图；如果朋友也需要试衣模特，生成五张透明 PNG 后
     放进 `data/model/`，或使用 `POST /api/model/images?angle=...`
4. **数据**
   - 第一次运行会自动创建 `data/`；不要把自己的真实数据提交到 Git
