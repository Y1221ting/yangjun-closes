## 三、本地运行

```bash
# 首次创建环境（Windows，Python 3.11）
py -3.11 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt

# 运行源码
.venv/Scripts/python.exe main.py
```

打包命令见根目录 README.md。

## 四、关键文件

| 文件 / 目录 | 说明 |
|-------------|------|
| `main.py` | 启动入口：备份数据库 → 建库 → 启动 HTTP → 开窗口 |
| `app/config.py` | 应用名、版本、数据目录、业务枚举 |
| `app/db.py` | 数据库结构与迁移（v8，含衣帽柜格位） |
| `app/services/` | 衣服、搭配、图片、备份、模特业务 |
| `app/api/` | 衣服、搭配、模特、回收站、导出接口 |
| `web/index.html` | 单页应用页面结构、等待封面、七只小人的挂载点 |
| `web/js/` | 衣柜、搭配、详情、模特卡片、设置、`mascots.js` 小人彩蛋等模块 |
| `web/css/theme-yelena.css` | 蓝水彩皮肤：外框、挂杆、衣帽柜、半透明格背、小人气泡 |
| `web/assets/` | 封面、Logo、应用图标、`characters/char1..7.webp` |
| `tests/` | 后端、旋转数学、UI 渲染测试 |
| `docs/07-模特与搭配展示规划.md` | 模特卡片与未来搭配切换方案 |
