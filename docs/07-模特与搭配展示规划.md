# 07 - 模特与搭配展示规划

> 目标：把基准模特放进程序，先作为固定试衣模特展示；以后每套搭配做好后，再逐步切换展示整套上身效果。

---

## 一、已确认的偏好（2026-11-20）

| 项目 | 决定 |
|------|------|
| 位置 | 放在「搭配」页顶部，做成模特主视觉卡片；下面是现有搭配库 |
| 展示 | 五角度可拖动旋转：正面 → 左前 45° → 侧面 → 左后 135° → 背面 |
| 背景 | 透明抠图 + 暖色衣帽间舞台（暖墙 + 木地板 + 柔和光 + 极淡脚底阴影） |
| 未来搭配 | 模特卡片顶部切换「基准模特 / 搭配 1 / 搭配 2」，下面配搭配缩略图 |
| 抠图 | 由用户在豆包完成；程序不安装 rembg，也不调用外部 AI |

## 二、第一版（本次实现）：只放基准模特

### 页面结构

```
搭配页
┌────────────────────────────────────────────┐
│ 搭配                         + 新建搭配     │
├────────────────────────────────────────────┤
│ 模特卡片                                    │
│ ┌──────────────┐  我的试衣模特              │
│ │ 暖色衣帽间舞台 │  五角度拖动旋转            │
│ │   透明模特     │  ● ○ ○ ○ ○               │
│ └──────────────┘  基准模特                  │
├────────────────────────────────────────────┤
│ 场景筛选 / 搜索                             │
├────────────────────────────────────────────┤
│ 搭配库卡片墙                                │
└────────────────────────────────────────────┘
```

- 模特卡片放在搭配库筛选栏上方。
- 没有模特图片时显示空状态，提示把五张透明 PNG 放入 `data/model/`。
- 第一版不做「搭配切换」；卡片右侧预留「搭配试穿 · 即将加入」提示。

### 图片处理

- 输入：用户在豆包抠好的五张透明 PNG。
- 统一输出：**1200×1600 透明 WebP**。
- 人物内容高度约 **1500px**，脚底基线 **1540px**，水平按脚底中心对齐。
- 五个角度分别保存：`data/model/{front,front45,side,back135,back}.webp`。
- 原始 PNG 保存在 `data/model/original/`。
- 模特图属于个人素材，已在 `.gitignore` 排除，不提交到 Git。

### 后端

- 新增 `app/services/model_service.py`：
  - `get_model()`：返回五个角度的路径、尺寸、版本时间。
  - `save_image(angle, raw)`：校验透明 PNG，处理成 1200×1600 透明 WebP。
- 新增接口：
  - `GET /api/model`：读取模特信息。
  - `POST /api/model/images?angle=front`：上传/替换单个角度（为以后更换模特预留）。
- 不改数据库结构。

### 前端

- 新增 `web/js/model-stage.js`：复用 `rotate-view.js`。
- 新增 `web/css/model.css`：秋日手作风模特卡片 + 暖色衣帽间舞台。
- 在 `web/index.html` 的 `page-outfits` 顶部加入模特卡片。
- 切到搭配页时加载模特；模特存在时显示旋转视图，不存在时显示空状态。

### 舞台视觉

- 暖米色墙面，底部木地板，柔和顶光。
- 模特透明站立，脚底用 CSS 画一圈很淡的椭圆阴影。
- 卡片使用纸色背景、行楷标题、少量胶带/枫叶装饰，和现有秋日手作风统一。
- 搭配画布和上身图展示台仍保持纯白；这个模特卡片只属于搭配页顶部。

## 三、第二版（以后做）：搭配切换

- 模特卡片顶部加切换：
  - 基准模特
  - 搭配 1 / 搭配 2 / …
- 选中一套搭配时，显示这套搭配的五角度上身图（复用同一个旋转视图）。
- 卡片下方加一排搭配缩略图，点击切换。
- 只有上传了上身图的搭配才出现在切换列表。
- 如果某套搭配没上传完整五角度，有几个角度显示几个，提示补齐。
