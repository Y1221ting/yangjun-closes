# 01 - 需求文档

> 个人衣柜 · 本地运行的服装库与搭配工具
> 文档版本：v1.0　|　编写日期：2026-11-18

---

## 一、项目定位

**个人衣柜**是一款完全在本机运行的个人服装库与搭配工具。用户把自己每件衣服拍成
「正面 / 侧面 / 背面」三张透明背景图导入程序，之后可以：

1. 在衣柜里分类浏览、筛选、搜索自己的全部衣服
2. 拖动鼠标让衣服「转起来」，看正、侧、后三个面
3. 在空白画布上自由拼贴出搭配（不受人体限制，想叠几层都行）
4. 搭配完成后一键「上身」，把整套衣服套到自己的全身照上预览
5. 搭配可以起名、打场景标签、存档，以后直接翻出来用
6. 把满意的搭配导出成一张图片

一句话：**先配衣服，再上身看效果；所有搭配一次做好，随时调用。**

---

## 二、目标用户与使用场景

### 用户
- 一个人使用，衣服数量约 30~100 件
- 不懂编程，需要双击就能运行的桌面程序
- 愿意为每件衣服花 1 分钟拍照并使用 AI 工具抠图
- 数据全部存在本机，不上传云端

### 典型场景

| 场景 | 用户想做什么 | 对应功能 |
|------|-------------|---------|
| 早上出门 | 不知道穿什么，翻一翻现成搭配 | 搭配库 + 场景筛选 |
| 买了新衣服 | 看看能跟现有哪几件搭 | 搭配画布 |
| 换季整理 | 看清有哪些衣服、哪些一直没穿 | 衣柜分类 + 颜色/季节筛选 |
| 面试 / 答辩 | 提前配好一套正式搭配，到时候直接穿 | 场景标签「正式」 |
| 想看看效果 | 不确定这身搭配穿在自己身上好不好看 | 上身预览 |

## 三、核心概念

| 概念 | 英文 / 字段 | 说明 |
|------|------------|------|
| **衣服** | garment | 衣柜里的一件单品，包含名称、类别、颜色等信息和三张角度图 |
| **角度图** | angle image | 正面 `front`、左前 45° `front45`、侧面 `side`、左后 135° `back135`、背面 `back`，至少三张透明背景 PNG |
| **类别** | category | 上衣 / 外套 / 下装 / 连衣裙 / 鞋 / 包 / 配饰 |
| **搭配** | outfit | 一组衣服 + 它们在画布上的位置、大小、层次 |
| **平铺视图** | flat view | 搭配的第一种视图：空白画布上只有衣服，没有人 |
| **上身视图** | worn view | 搭配的第二种视图：衣服套在模特（用户全身照）身上 |
| **场景标签** | scene | 这套搭配适合的场合，如「日常」「社交」「休闲」「正式」 |
| **槽位** | slot | 模特身上每个类别对应的默认位置（上衣在胸口、鞋在脚部等） |

> 关键设计：**平铺视图和上身视图共用同一组衣服**，但各自保存一套位置坐标。
> 在平铺视图里调好的搭配，切到上身视图时由程序按类别自动摆好，用户可再微调。

## 四、核心流程

### 4.1 首次准备（用户一次性操作，程序不参与）

1. 把衣服挂起来，拍「正面 / 侧面 / 背面」三张照片
2. 用即梦 / 通义 / 其他 AI 工具把三张照片抠成**透明背景 PNG**
3. 打开程序，导入这三张图

> 程序不负责抠图，也不调用任何 AI 服务。这样做的好处：程序体积小、不产生费用、
> 不依赖网络、抠图效果由用户自己把关。

### 4.2 录入一件衣服

```
点击「添加衣服」
   ↓
选择三张 PNG（正 / 侧 / 后）
   ↓
填写信息（类别、名称、颜色、季节、场合均为点选，不用打字）
   ↓
程序自动裁剪空白、统一比例、生成缩略图
   ↓
保存，出现在衣柜里
```

**录入一次，永久保存**，以后不用重复输入。

### 4.3 做一套搭配（平铺视图）

```
新建搭配
   ↓
左侧衣柜列表 → 把衣服拖到画布
   ↓
自由摆放、滚轮缩放、调整前后层次
   ↓
起名字（如「周末出门」）、选场景标签
   ↓
保存
```

画布上**没有人体**，衣服可以任意组合、叠穿：
外套盖住上衣、包提在手里、围巾搭在肩上。

### 4.4 上身预览

```
在搭配里点「上身」
   ↓
模特照片出现（用户自己的全身照）
   ↓
每件衣服按类别自动吸附到槽位：
   外套 → 肩部     上衣 → 胸口     下装 → 腿部
   鞋   → 脚部     包   → 手侧
   ↓
用户微调位置 / 大小 / 层次
   ↓
单独保存这套的「上身版」
```

再次打开这套搭配时，程序记住用户手动调过的位置，不再重新自动摆放。

### 4.5 使用搭配

```
打开搭配库
   ↓
按场景标签筛选（日常 / 社交 / 休闲 / 正式 / 自定义）
   ↓
点开某套 → 看平铺版或上身版
   ↓
导出成图片 / 直接照着穿
```

## 六、界面设计

### 6.1 风格：秋日手作风（2026-11-20 起）

| 项目 | 取值 |
|------|------|
| 页面背景 | `#F6EFE1` 纸色 |
| 卡片 / 面板背景 | `#FBF6EC` / `#FFFDF7` |
| 分割线 / 描边 | `#E6D7BF`，侧栏用虚线 |
| 主文字 | `#4A3526` 棕墨 |
| 次要文字 | `#8D7660` |
| 强调色（按钮、选中） | `#6D4426` 棕底米白字 |
| 危险操作 | `#B0482F` 枫叶红 |
| 圆角 | 卡片 14px，按钮 10px |
| 字体 | 标题用「华文行楷」，正文用微软雅黑 |
| 装饰 | 纸纹、和纸胶带、干花树叶（取自欢迎页花体图） |
| 间距单位 | 8px 的倍数 |

> 风格后期可更换：所有颜色和尺寸都写在 CSS 变量里，换皮肤只改变量，不动功能代码。
> **例外**：搭配画布与上身图展示台保持纯白，避免影响拼贴和导出效果。

### 6.1.1 图片视觉风格（2026-11-18 确定）

衣柜里的**衣服图片**统一使用 **3D 皮克斯动画风格**：

- 每件衣服三张角度图（正 / 侧 / 后）都由用户在外部 AI 工具中生成后导入
- **模特也使用同一画风的动漫形象**，不使用真人照片
- 程序界面采用秋日手作风，不随衣物图片风格改变
- 先试做 5 件验证画风一致性，通过后再扩大到全部衣物

> 提示词见 `prompts/3D动漫风格提示词.md`。程序只负责显示，不做任何风格转换。

### 6.2 页面结构

```
┌──────────┬────────────────────────────────────────┐
│ 花体招牌  │  衣柜  搜索 / 筛选 / 添加              │
│ yt的衣柜  │                                        │
│ 衣柜 搭配 │  ┌──────────────────────────────────┐  │
│ 设置     │  │ 上衣   ═══挂杆═══════════════════ │  │
│          │  │ 外套   ═══挂杆═══════════════════ │  │
│ 衣橱目录  │  │ 下装   ═══挂杆═══════════════════ │  │
│ 全部/上衣 │  │ 连衣裙 ═══挂杆═══════════════════ │  │
│ 外套/…   │  │ 配饰 + 衣帽柜                     │  │
│          │  └──────────────────────────────────┘  │
└──────────┴────────────────────────────────────────┘
```

| 页面 | 内容 |
|------|------|
| **衣柜** | 左侧衣橱目录；顶部搜索 / 筛选弹层 / 添加；分类挂杆视图 |
| **衣服详情** | 左侧旋转展示区，右侧信息面板 |
| **搭配库** | 搭配封面网格 + 场景筛选 |
| **搭配编辑** | 左侧衣柜抽屉，中间大画布，右侧属性面板 |
| **设置** | 数据备份、启动欢迎页开关、回收站 |

### 6.3 交互原则

- 任何操作 0.2 秒内要有视觉反馈
- 拖动时有轻微放大和阴影，松手回弹
- 删除操作二次确认
- 保存自动进行，顶部只提示「已保存」，不弹窗打断
- 不使用弹窗式表单：信息录入用右侧抽屉
- 启动欢迎页约 1.6 秒后自动淡出，点击或按键可跳过，可在设置里关闭

## 七、明确不做的事（项目边界）

| 不做 | 原因 |
|------|------|
| 真 3D 建模、衣服物理模拟 | 需要专业扫描与布料仿真，个人项目无法实现 |
| 自动抠图 | 用户已有 AI 工具，程序内置模型体积大、效果难保证 |
| 在线购物 / 支付 / 库存 | 与个人衣柜无关 |
| 云同步 / 多设备 | 需求明确要求本地运行 |
| 社交分享 | 只导出图片即可 |
| 穿搭日历（v1） | 首版聚焦「衣柜 + 搭配」，日历放 P2 |
| 手机 App | 首版 Windows 桌面 |

## 八、非功能性要求

| 项目 | 要求 |
|------|------|
| 数据量 | 30~100 件衣服，每件 3 张图 |
| 启动速度 | 双击到显示衣柜 < 5 秒 |
| 衣柜加载 | 100 件缩略图 < 1 秒（懒加载 + webp） |
| 数据安全 | 只存本机；SQLite 开启 WAL；搭配编辑自动保存 |
| 稳定性 | 数据库操作失败不崩溃，界面给出可读的错误提示 |
| 可迁移 | 整个 `data/` 目录拷走即可换电脑使用 |
| 交付形式 | 单个 `个人衣柜.exe`，双击运行（界面显示名 yt的衣柜） |
