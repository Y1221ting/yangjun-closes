## 使用顺序

```
① 正面（提示词 A）→ 满意后保存
② 侧面（提示词 B，把正面图一起上传）
```

## 提示词 A · 正面（皮克斯风）

```text
【任务】
参考我上传的这张照片里这件米白色连帽羽绒服，重新绘制成 3D 皮克斯动画风格的服装单品图。

【风格】
3D 皮克斯动画电影风格，Pixar / Disney 质感，圆润柔和的造型，
卡通渲染，非照片写实，细腻但简化的布料褶皱，柔和次表面散射，
电影级柔光，纯白色背景（#FFFFFF），无投影

【衣服特征（必须保留）】
- 米白色 / 奶油色连帽羽绒服
- 横向绗缝，一格一格的蓬松感
- 前面中间一条浅色拉链，拉链头在上方
- 左右两侧各一个斜向拉链口袋
- 下摆左右各一个抽绳扣
- 袖口是松紧收口
- 帽子是立体的，内部也有绗缝
- 短款版型，到胯部，微宽松

【画面要求】
- 正面视角，镜头与衣服中心等高，无透视变形
- 衣服平铺或自然展开，不穿在任何人身上
- 纯白色背景 #FFFFFF，无渐变、无投影、无地面
- 柔和均匀的棚拍光，光源在左上方
- 衣服完整入画，水平垂直居中，占画面高度约 75%
- 用卡通风格表现面料：柔和的块面高光和阴影，不要真实布料纹理

【必须去掉】
我本人、脸、手、腿、身体、头发、手机、镜子、房间、床、衣柜、衣架

【不要】
- 不要照片写实风格
- 不要真实布料纹理、毛孔级细节
- 不要改变衣服颜色、款式、口袋数量、拉链位置
- 不要添加任何图案、文字、logo
- 不要阴影、投影、边框、水印
```

## 提示词 B · 侧面（严格 90°）

**上传提示词 A 生成的正面图，再粘贴这段。**

```text
【任务】
参考这张 3D 皮克斯动画风格的米白色羽绒服单品图，生成同一件衣服的严格 90 度正侧面图。

【必须完全一致】
- 画风：同样的 3D 皮克斯动画风格、卡通渲染、非照片写实
- 配色：米白色
- 细节：横向绗缝、浅色拉链、松紧袖口、下摆抽绳
- 光照：左上方柔光，纯白色背景，无投影

【视角】
- 相机绕到衣服正侧方，与正面图成 90 度，同一高度
- 必须是严格的正侧面，不要 45 度斜侧视角
- 只看到衣服的侧面轮廓：袖子侧边、衣身厚度、侧缝、下摆的侧面弧度
- 帽子在侧面呈现为突出的立体轮廓
- 拉链在侧面只露出一条细边

【画面】
- 纯白色背景 #FFFFFF，无渐变、无投影
- 衣服完整居中，高度与正面图一致，约占画面高度 75%
- 卡通渲染，非照片写实

【不要】
- 不要出现人、模特、衣架、道具
- 不要添加新图案或装饰
- 不要透视变形、阴影、文字、水印
```

## 提示词 D · 皮克斯虚拟形象（改进版）

**上传你的正面全身照，再粘贴这段。**

```text
【任务】
参考这张我的全身照片，生成我的 3D 皮克斯动画风格虚拟形象，用于虚拟试衣。

【风格】
3D 皮克斯动画电影风格，Pixar / Disney 质感，圆润柔和的造型，
卡通渲染，非照片写实，柔和次表面散射，电影级柔光，
纯白色背景（#FFFFFF），无投影

【保留我的特征】
- 大致脸型、五官比例
- 发型：黑色长发、双麻花辫、齐刘海
- 戴黑框圆眼镜
- 身形偏瘦、中等身高

【姿态】
- 正面自然站立，面朝镜头
- 双臂自然下垂，与身体保持明显空隙（至少一个拳头宽），不要贴住身体
- 双腿并拢或自然分开，双腿完整露出
- 不要摆姿势、不要道具

【服装要求（重要）】
- 只穿最简单的浅色贴身打底：白色吊带 + 浅灰色紧身短裤
- 赤脚，不穿鞋、不穿袜子
- 不要配饰、不要包包，眼镜除外

【画面】
- 全身完整入画：头顶到脚底
- 头顶留约 5% 空白，脚底留约 5% 空白
- 纯白色背景 #FFFFFF，无渐变、无地面、无投影
- 柔和均匀的光照，与衣物单品图一致
- 人物居中，约占画面高度 90%

【不要】
- 照片写实、真人质感
- 运动鞋、鞋子、袜子
- 地板阴影、渐变背景
- 复杂服装、图案、配饰
- 侧身、走姿、夸张表情
```

## 常见问题速查

| 现象 | 原因 | 改法 |
|------|------|------|
| 生成出来还是写实照片 | 风格词被参考照片带偏 | 把「【风格】」整段放到提示词最前面；负向加「照片写实、真实布料纹理」 |
| 背景是米白渐变 | 模型默认柔光背景 | 强调「纯白色背景 #FFFFFF，无渐变、无地面、无投影」 |
| 侧面变成 45° 斜侧 | 模型对「侧面」理解模糊 | 强调「严格 90 度」「相机与正面成直角」「不要 45 度斜侧」 |
| 背面凭空多了图案 | 模型自己脑补 | 强调「背面是连贯的横向绗缝，不要编造图案」 |
| 模特穿鞋 / 有地板阴影 | 默认全身照习惯 | 用提示词 D，明确「赤脚、无地板、无投影」 |
| 正面和背面颜色有偏差 | 两次生成分别理解颜色 | 生成侧面/背面时把正面图作为参考图一起上传，并强调「配色必须完全一致」 |
| 衣服大小一张大一张小 | 构图随机 | 每张都要求「占画面高度约 75%，居中」 |

## 生成后检查清单

- [ ] 是卡通/皮克斯感，不是照片
- [ ] 背景是纯白，没有渐变和阴影
- [ ] 米白色没有偏黄或偏灰
- [ ] 横向绗缝、斜拉链口袋、下摆抽绳都在
- [ ] 正面、侧面、背面三张大小接近
- [ ] 没有人、手、手机、衣架、房间
- [ ] 模特赤脚、无鞋、无地板阴影
- [ ] 最后导出的是透明背景 PNG
