# 3D 动漫风格衣物生成提示词

> 适用于：镜面自拍 / 穿着照 → 3D 动漫风格衣柜
> 配套工具：即梦、可灵、豆包、通义、Nano Banana（Gemini）、ChatGPT
> 版本：v1.1　|　2026-11-18

> **✅ 本项目已选定：风格 A · 皮克斯 / 迪士尼 3D 动画风**
> 衣物三视角与模特形象统一使用该风格；先试做 5 件验证一致性，再扩大范围。

## 本项目固定风格描述（每次生成都复制这一段）

```text
3D 动画电影风格，Pixar / Disney 质感，圆润柔和的造型，
细腻的布料褶皱，柔和的次表面散射，电影级柔光，
高精度渲染，干净通透，纯白色背景
```

## 一、结论先行

| 你的问题 | 答案 |
|---------|------|
| 对着镜子拍的照片 AI 能识别吗？ | ✅ 能。衣服的款式、配色、图案都能认出来 |
| 纹理不用那么清晰可以吗？ | ✅ 可以，而且**降低了难度**——不用死磕细节，AI 不容易翻车 |
| 3D 动漫效果能做吗？ | ✅ 能，但**必须全项目统一一种风格**，不能这件皮克斯、那件原神 |

> 动漫风格的最大好处：AI 画风本身就是「概括」的，三张角度图之间的细微不一致
> 会被画面风格掩盖掉，旋转时反而更难看出破绽。

## 二、镜面自拍的 5 个坑与处理方式

| 问题 | 表现 | 提示词里的处理 |
|------|------|--------------|
| 镜像翻转 | 衣服上的文字、logo 左右反了 | 「文字图案方向必须正常，不是镜像」 |
| 手机遮挡 | 胸口或腹部被手机挡住 | 「去除手机，按衣服对称性补全遮挡部分」 |
| 穿着褶皱 | 看不出平铺形状 | 动漫风重绘会自动概括，问题不大 |
| 光线不均 | 一边亮一边暗 | 「统一为柔和均匀的棚拍光」 |
| 背景杂物 | 房间、床、衣柜 | 「纯白背景，不保留任何背景元素」 |

## 三、第一步：先定风格（全项目只能用一种）

选一个，之后**所有衣服、模特、背景都用同一种描述**。

### 风格 A · 皮克斯 / 迪士尼 3D 动画　✅ 本项目已选定

**感觉**：圆润、温暖、像动画电影角色，质感偏软。
**适用**：想要治愈、柔和、有童话感的衣柜。

```text
3D 动画电影风格，Pixar / Disney 质感，圆润柔和的造型，
细腻的布料褶皱，柔和的次表面散射，电影级柔光，
高精度渲染，干净通透
```

### 风格 B · 3D 二次元 / 赛璐璐（原神风）

**感觉**：清晰描边、色彩鲜艳、偏二次元，像游戏里的角色和道具。
**适用**：想要「游戏衣柜 / 换装游戏」的感觉。

```text
3D 二次元赛璐璐风格，Genshin Impact 质感，
清晰的描边线，鲜艳通透的色彩，卡通渲染，
干净利落的布料质感，明亮均匀的光照
```

### 风格 C · 盲盒手办 / 泡泡玛特风

**感觉**：像摆在桌上的高级搪胶手办，圆润、有光泽、精致。
**适用**：想要「收藏品」的感觉，衣服有手办玩具的精致感。

```text
Pop Mart 盲盒手办风格，高级搪胶质感，
圆润精致的小比例造型，柔和的棚拍光，
商品展示级渲染，细腻的表面高光
```

### 风格 D · 黏土 / 定格动画

**感觉**：像手工捏的黏土小人，哑光、有手工痕迹。
**适用**：想要手作、可爱、文艺的感觉。

```text
黏土动画风格，手工黏土质感，柔和的哑光表面，
轻微的捏塑痕迹，定格动画的柔和光影，温暖朴素
```

## 四、关键技巧：先做一张「风格锚点图」

这是保证整个衣柜画风统一的**最重要一步**。

### 做法

1. 先拿**一件最普通的白 T 恤**，用下面的【提示词 A】生成一张动漫风单品图
2. 如果满意，这张图就是「风格锚点」
3. 之后**每次生成新衣服时，都把这张锚点图一起上传**，提示词里加一句：
   `风格必须与参考图的画风、光照、背景完全一致`

> 没有这一步，30 件衣服会有 30 种画风，衣柜看起来会像大杂烩。

## 五、核心提示词

### 【提示词 A】镜面自拍 → 3D 动漫风单品图（正面）

**用法**：上传你的镜面自拍照（穿着这件衣服），粘贴提示词。
**先替换**：`<风格描述>` 换成第三节你选的那段。

```text
【任务】
参考这张照片里我身上穿的这件衣服，重新绘制成 3D 动漫风格的服装单品展示图。

【风格】
<风格描述，例如：3D 二次元赛璐璐风格，Genshin Impact 质感，
清晰的描边线，鲜艳通透的色彩，卡通渲染，干净利落的布料质感>

【要参考衣服的这些特征】
- 款式与版型：<T恤 / 衬衫 / 卫衣 / 针织衫 / 外套 / 长裤 / 半身裙 / 连衣裙>
- 主色与配色：<如 米白色主体，袖口深棕色>
- 图案与文字：大致的位置、内容、风格（不需要像素级还原）
- 领口、袖型、下摆长度
- 大致的面料感觉：<棉 / 针织 / 牛仔 / 雪纺 / 皮革>

【画面要求】
- 视角：正面，衣服平铺或自然展开，完整展示整件衣服
- 形态：不穿在任何人身上，是独立的一件衣服
- 背景：纯白色，干净无投影
- 光线：柔和均匀的棚拍光，左上或右上方单一主光
- 构图：衣服完整入画，水平垂直居中，占画面高度约 75%
- 细节：缝线、纽扣、拉链、口袋用简化的动漫风格表现

【必须去掉】
- 我本人、我的脸、手、腿、身体、头发
- 手机、镜子、镜框、房间、床、衣柜
- 所有背景元素

【必须修正】
- 如果衣服上有文字或 logo，方向必须是正常阅读方向，不能是镜像翻转的
- 被手机挡住的部分，按衣服的对称性和版型合理补全
- 穿着时产生的过度褶皱，恢复成自然平整的状态

【绝对不要】
- 不要改成别的款式、别的颜色
- 不要添加原衣服没有的图案、文字、装饰
- 不要照片写实风格（本次要的是动漫风格）
- 不要阴影、投影、文字标注、水印、边框
```

**英文版**：

```text
Task: Using the garment I'm wearing in this mirror selfie as reference,
redraw it as a stylized 3D anime-style clothing product image.

Style: <your chosen style, e.g. "3D cel-shaded anime style, Genshin Impact
aesthetic, clean outlines, vibrant colors, toon shading, clean fabric rendering">

Reference these features of the garment:
- Type and fit: <t-shirt / shirt / hoodie / knitwear / jacket / pants / skirt / dress>
- Main color and accents: <e.g. cream body with dark brown cuffs>
- Graphics and text: approximate position and content, not pixel-perfect
- Neckline, sleeve type, hem length
- Approximate fabric feel: <cotton / knit / denim / chiffon / leather>

Requirements:
- View: straight-on front, garment laid flat or naturally spread out
- Form: a standalone garment, NOT worn by anyone
- Background: pure white, clean, no shadows
- Lighting: soft, even studio light from a single key light (upper left or upper right)
- Framing: entire garment visible, centered, occupying about 75% of image height
- Details: stitching, buttons, zippers and pockets rendered in a simplified anime style

Remove: me, my face, hands, legs, body, hair; the phone, mirror, mirror frame,
room, bed, wardrobe; any background elements.

Correct: if the garment has text or a logo, it must read in the normal direction,
not mirrored; complete the area hidden by the phone based on symmetry and fit;
smooth excessive wrinkles caused by wearing into a natural, flat shape.

Do not: change the style or color of the garment; add graphics, text or
decorations that don't exist; use a photorealistic style; add shadows, drop
shadows, text overlays, watermarks or borders.
```

### 【提示词 B】动漫风单品 → 严格侧面

**用法**：先把【提示词 A】生成的正面图保存，再上传它生成侧面。

```text
【任务】
参考这张 3D 动漫风格的服装单品图，生成同一件衣服的「严格 90 度侧面图」。

【必须完全一致】
- 画风、描边粗细、渲染质感
- 光源方向、色温、亮度
- 配色、图案、材质表现
- 衣服的整体比例、长度、宽度

【视角要求】
- 相机绕到衣服正侧方，与正面图成 90 度，同一高度
- 必须是严格的正侧面，不是 45 度斜侧
- 画面只显示衣服的侧面轮廓：
  袖子侧边、衣身厚度、侧缝线、下摆的侧面弧度
- 袖子长度与正面图一致（短袖就是短袖）

【画面要求】
- 纯白色背景，无投影
- 与正面图完全相同的光照
- 衣服完整居中，高度与正面图一致（约画面高度的 75%）

【不要】
- 不要出现人、模特、衣架、道具
- 不要添加正面图里没有的图案或装饰
- 不要改变衣服的版型和长度
- 不要生成透视图、剖面图
```

### 【提示词 C】动漫风单品 → 严格背面

```text
【任务】
参考这张 3D 动漫风格的服装单品图，生成同一件衣服的「正背面图」。

【必须完全一致】
- 画风、描边、渲染质感、光照方向
- 配色、材质表现
- 领口、肩线、袖口、下摆的形状
- 衣服的比例和长度

【视角要求】
- 相机绕到衣服正后方 180 度，同一高度
- 严格正对背面，无透视变形

【背面设计规则】
- 如果这件衣服背面是纯色，就保持纯色
- 如果正面有图案，不要把正面图案复制到背面
- 拿不准背面长什么样时，选择最简洁的纯色方案，不要编造复杂设计
- 如果照片里能看到背面的一部分，严格以那一部分为准

【画面要求】
- 纯白色背景，无投影
- 与正面图相同的光照
- 衣服居中，高度与正面图一致

【不要】
- 不要编造背面图案、文字、标签、吊牌
- 不要出现人、模特、衣架
```

### 【提示词 D】已有真实商品图 → 动漫风

**用法**：如果你已经有一张干净的白底真实图，想统一转成动漫风。

```text
【任务】
把这张真实的衣服商品图，转换成 <风格描述> 的 3D 动漫风格单品图。

【保持】
- 款式、版型、长短、宽窄
- 主色与配色
- 图案的位置与内容
- 衣服的整体比例

【改变】
- 材质表现：简化成动漫风格的质感，不追求真实布料细节
- 光影：改成柔和均匀的棚拍光
- 整体画风：<风格描述>

【画面要求】
- 纯白色背景，无投影
- 衣服完整居中，占画面高度约 75%
- 与之前的单品图保持同一光照方向

【不要】
- 不要改变衣服的款式、颜色、图案内容
- 不要添加新装饰
- 不要写实照片风格
```

### 【提示词 E】生成你的 3D 动漫形象（模特）

**重要**：如果衣服是动漫风，模特也**必须**是动漫风，否则「真人 + 动漫衣服」会很怪。

**用法**：上传一张你的正面全身照，生成虚拟形象。

```text
【任务】
参考这张我的全身照片，生成我的 3D 动漫风格虚拟形象。

【风格】
<与衣物完全相同的风格描述>

【姿态要求】
- 正面自然站立，面朝镜头
- 双臂自然下垂，与身体保持一点距离，不要交叉抱胸
- 双腿并拢或自然分开，双脚完整露出
- 不要摆姿势、不要道具、不要包包

【服装要求】
- 穿最简单的中性打底：白色贴身背心 + 浅灰色短裤
- 不要穿真实衣柜里的衣服
- 不要复杂图案、不要配饰

【画面要求】
- 全身完整入画：头顶到脚底
- 头顶留约 5% 空白，脚底留约 5% 空白
- 纯白色或极浅灰色背景，不要投影
- 光线：柔和均匀，与衣物单品图相同

【面部】
- 保留我的大致五官特征和发型
- 做适度的动漫化处理，不要过度夸张
- 表情自然、平静

【不要】
- 不要写实照片风格
- 不要复杂的背景、场景、道具
- 不要摆时尚大片姿势
```

> **生成后的用途**：把这张图上传到程序的「设置 → 模特照片」，
> 所有搭配都能套到这个形象上。

## 七、一致性检查清单

每件新衣服生成完，对照检查：

- [ ] 画风与「风格锚点图」看起来像同一套作品
- [ ] 光照方向一致（都从左上或都从右上打光）
- [ ] 背景白色色值一致（不能一张纯白一张偏灰）
- [ ] 衣服在画面中的大小占比一致（约 75%）
- [ ] 正面、侧面、背面三张的配色没有明显色差
- [ ] 三张衣服的宽度比例合理（侧面最窄，正面和背面相近）
- [ ] 没有残留手机、镜子、人脸、背景元素
- [ ] 文字方向正常（没有镜像）

**任意一项不通过就重新生成**，不要将就——一件将就，整面衣柜都别扭。

## 八、常见问题与修正

| 问题 | 原因 | 怎么改 |
|------|------|--------|
| 生成的还是真人/写实风 | 风格描述被参考照片带偏 | 把风格描述放到提示词最前面；加重负向词「照片写实、真人」 |
| 三张图色差明显 | 每次生成重新理解颜色 | 用第一张图作为参考图生成后两张，并强调「配色必须完全一致」 |
| 侧面不像自己那件 | 动漫风格简化过度 | 在提示词里补充细节：「袖口有罗纹收口」「下摆有开衩」 |
| 背面凭空多出图案 | AI 脑补 | 提示词强调「背面保持纯色，不要复制正面图案」 |
| 衣服比例忽大忽小 | 构图随机 | 统一要求「占画面高度 75%，居中」 |
| 画风混搭 | 换了工具或会话 | 同一项目固定一个工具；每次带上风格锚点图 |
| 模特衣服和单品画风不一致 | 分别用不同提示词生成 | 模特提示词必须复用完全相同的风格描述段 |

## 九、推荐流程（一件衣服约 5 分钟）

```
① 对镜自拍（穿着这件衣服，正面站姿）
        ↓
② 【提示词 A】生成正面单品图
        ↓  满意？
        ├─ 不满意 → 调整风格描述 / 补充细节 / 重试
        ↓ 满意
③ 用正面图 + 【提示词 B】生成侧面
        ↓
④ 用正面图 + 【提示词 C】生成背面
        ↓
⑤ 三张图对照检查清单
        ↓
⑥ 用平台自带「抠图」导出透明 PNG
        ↓
⑦ 导入个人衣柜
```

## 十、一句话总结

> **风格先定死，锚点先做好，然后一件一件来。**
> 动漫风容错高，但统一性要求更高——30 件衣服必须看起来像同一个画师画的。
