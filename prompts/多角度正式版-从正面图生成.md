# 多角度正式版 · 从一张正面图生成侧/背/45°

> 所有提示词都基于你上传的正面图，整段复制，不用改字
> 适用于即梦 / 可灵 / 豆包 / 通义 / Nano Banana / ChatGPT
> 2026-11-18

---

## 两种路线，先选一个

### 路线 1：保持照片写实风（最省事）

```
已有正面图（写实）
   ↓ 直接用【提示词 B】→ 侧面
   ↓ 直接用【提示词 C】→ 背面
   ↓ 抠图导入
```

**优点**：不用重做已有的 15 张正面图，今天就能用。
**代价**：和你那个皮克斯模型不搭——需要把模特也换成写实风。

### 路线 2：统一成皮克斯风（推荐，和你的模型统一）

```
已有正面图（写实）
   ↓ 【提示词 A】→ 皮克斯风正面（保存）
   ↓ 用皮克斯正面 + 【提示词 B】→ 侧面
   ↓ 用皮克斯正面 + 【提示词 C】→ 背面
   ↓ 抠图导入
```

**优点**：整柜画风统一，和现有虚拟形象配套。
**代价**：每件多一步 A。

> 下面的 D / E 是 45° 和 135° 两个补充角度，**可选**。
> 只做正 / 侧 / 背三张也能用，程序会做翻转过渡。

## 批量版 · 一张图生成五个角度（可选）

> **适用场景**：想省掉五次生成，一次性拿到全部角度。
> **代价**：五个视角挤在一张图里，每个视角的分辨率会下降；如果要求每张都和单独生成一样清晰，请继续用下面的逐张提示词。
> **效果不变的部分**：画风、配色、结构细节、光照、纯白背景，与逐张版本完全一致。

**上传这张单品的正面图，整段复制：**

```text
【任务】
以我上传的这件单品的正面图为参考，生成一张「五视角转面图」：
在同一张横向长图里，并排展示同一件单品的五个角度。

【画面布局】
- 从左到右依次为：正面、左前 45°、左侧面、左后 135°、正背面
- 五个视角等宽、等间距，排成一行
- 每个视角都完整展示整件单品，不裁切、不重叠
- 视角之间留出均匀的纯白色间隔
- 整张图为超宽横向构图，宽高比约 5:2（或使用平台支持的最宽横图）
- 不要任何文字、编号、箭头、分隔线、边框、水印

【五个视角都必须完全一致】
- 同一件单品：款式、版型、长短、宽窄
- 同一种颜色和配色，五张之间不能有色差
- 同一套图案、文字、logo、刺绣，位置和内容不变
- 同样的结构细节：领口、袖型、口袋、拉链、纽扣、抽绳、腰带、肩带
- 同样的画风：3D 皮克斯动画电影风格，Pixar / Disney 质感，
  圆润柔和的造型，卡通渲染，非照片写实
- 同样的光照：左上方柔光，纯白色背景 #FFFFFF，无渐变、无地面、无投影
- 五个视角的单品大小一致、垂直居中对齐

【各视角要求】
- 正面：正对镜头
- 左前 45°：相机向左转 45°，能看到正面和左侧面
- 左侧面：严格 90° 正侧面，体现真实厚度，不要压扁
- 左后 135°：相机转到左后方 135°，看到背面和左侧面
- 背面：正对背面，保持纯色或最简设计，不要复制正面图案

【不要】
- 不要出现人、模特、手、腿、衣架、道具
- 不要在五个视角之间改变颜色、大小或细节
- 不要添加正面图没有的图案、文字、装饰
- 不要阴影、投影、文字、水印、边框
- 不要拼成大小不一的排版，必须是等宽并排
```

**生成后自动切图：**

```bash
.venv/Scripts/python.exe tools/split_turnaround.py 转面图.png
```

脚本会自动识别五个视角、裁掉多余白边，输出到 `衣服设计图/五视图拆分/`。
然后再用平台「智能抠图」批量处理这五张。

## 提示词 A · 正面图转皮克斯风（路线 2 用）

**上传你已有的正面图，整段复制。**

```text
【任务】
把这张服装正面图，转换成 3D 皮克斯动画风格的服装单品图。

【严格保留】
- 这件单品的款式、版型、长短、宽窄
- 主色和所有配色，不要偏色
- 所有图案、文字、logo、刺绣的位置和内容
- 领口、袖型、口袋、拉链、纽扣、抽绳、腰带、肩带等结构细节
- 面料大致的质感（棉、针织、牛仔、羽绒、皮革等）

【只改变画风】
- 照片写实 → 3D 皮克斯动画电影风格，Pixar / Disney 质感
- 真实布料纹理 → 简化的卡通块面高光和柔和阴影
- 摄影光影 → 柔和均匀的棚拍光，光源在左上方
- 背景 → 纯白色 #FFFFFF，无渐变、无地面、无投影
- 整体圆润柔和，卡通渲染，非照片写实

【画面】
- 保持原来的正面视角和构图，不要改变角度
- 单品完整居中，占画面高度约 75%

【不要】
- 不要改变款式、颜色、图案、结构
- 不要添加或删除任何细节
- 不要出现人、手、衣架、道具、手机、房间
- 不要阴影、投影、文字、水印、边框
- 不要改变单品的比例和长短
```

## 工具操作（以即梦为例）

1. 打开「图片生成 → 图生图 / 图片编辑」
2. 上传**正面图**（路线 2 请上传 A 生成的皮克斯正面）
3. 整段粘贴对应提示词
4. 一次生成 4 张，和正面图并排对比，选最一致的那张
5. 保存为 PNG
6. 用「智能抠图」导出透明背景
7. 导入个人衣柜

> 关键：**侧面和背面一定要以正面图为参考图上传**。只写文字不传图，颜色和画风都会跑偏。

## 生成后怎么判断能不能用

| 检查项 | 通过标准 |
|--------|---------|
| 画风 | 和正面图看起来是同一套 |
| 颜色 | 并排看不出色差 |
| 大小 | 高度接近，占画面比例接近 |
| 结构 | 拉链、纽扣、口袋的位置对得上 |
| 厚度 | 侧面不是一张纸，有合理体积 |
| 背景 | 纯色、无渐变、无阴影 |
| 干净度 | 没有人、手、衣架、房间 |

任何一项明显不对就重生成，**不要将就**——三张里有一张不对，旋转时就会明显跳。

## 三张还是五张？

| 方案 | 需要的图 | 效果 |
|------|---------|------|
| **三张（推荐先做）** | 正面、侧面、背面 | 程序做翻卡过渡，够用 |
| 五张 | 正面、左前 45°、侧面、左后 135°、背面 | 拖动更连贯，但 AI 生成的不一致风险更高 |

建议先把三张跑通，觉得旋转时跳跃明显，再加 45°/135°。
程序的阶段 3 会按「帧序列」实现，加几张图都能支持。
