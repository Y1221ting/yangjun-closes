# 衣物图片生成提示词包

> 用于即梦 / 可灵 / 豆包 / 通义 / Nano Banana（Gemini）/ ChatGPT 等图像 AI
> 版本：v1.0　|　2026-11-18

---

## 〇、先看这个（很重要）

### 三条铁律

| 铁律 | 说明 |
|------|------|
| **保真** | 衣服的颜色、图案、文字、logo、纽扣、拉链、缝线，一个都不能变 |
| **统一** | 正 / 侧 / 后三张图，衣服大小、位置、光线必须一致，否则旋转时会跳 |
| **白底** | AI 输出统一用纯白背景，最后再用抠图工具去背景；不要指望 AI 直接输出透明 PNG |

### AI 能做什么、不能做什么

| 任务 | 能不能交给 AI | 说明 |
|------|-------------|------|
| 把手机随手拍的照片整理成商品图 | ✅ 很擅长 | 去背景杂物、摆正、均匀打光 |
| 抠掉背景变成透明 PNG | ✅ 用工具的「抠图」功能 | 比写提示词可靠 |
| 从正面图推断**侧面** | ⚠️ 勉强 | 纯色衣服还行，有图案/logo 会失真 |
| 从正面图推断**背面** | ❌ 不可靠 | 背面图案 AI 只能瞎编，必须实拍 |
| 生成真正的 3D 旋转 | ❌ 不是提示词的事 | 靠三张图 + 程序代码实现 |

> **结论：侧面和背面请一定实拍。AI 只用来整理和抠图。**

## 一、标准工作流

```
手机拍照（正/侧/后）
   ↓
【提示词 1】AI 整理成纯白底商品图
   ↓
【提示词 4】如果有需要，统一三张图的画幅
   ↓
用工具自带的「抠图 / 消除背景」输出透明 PNG
   ↓
导入个人衣柜
```

如果某件衣服实在拍不了侧面（比如挂着的连衣裙），再考虑【提示词 2】。

## 二、必用提示词

### 【提示词 1】把随手拍的衣服照片整理成商品图

**什么时候用**：衣服挂在门后、床上、沙发上拍的，背景很乱。
**怎么用**：上传原图 + 粘贴下面的提示词。

```text
【任务】
把这张手机随手拍的衣服照片，整理成一张专业的电商产品图。

【必须原样保留】
- 衣服的款式、版型、长短、宽窄
- 颜色、色相、饱和度
- 所有图案、印花、文字、logo、刺绣
- 纽扣、拉链、口袋、抽绳、标签、缝线、走线
- 面料的纹理与质感

【必须做到】
- 视角：正视图，镜头与衣服中心等高，正对镜头，无透视变形，无倾斜
- 形态：衣服自然平铺或自然垂挂，表面平整，无遮挡、无堆积的褶皱
- 背景：纯白色（#FFFFFF），干净、均匀
- 光线：柔和均匀的摄影棚柔光，受光均匀，没有明显高光斑和硬阴影
- 构图：整件衣服完整入画，四周留出约 8% 的空白，衣服水平垂直都居中

【绝对禁止】
- 不要出现人、手、模特、身体部位
- 不要出现衣架、夹子、挂钩、绳索、背景墙、地板、家具
- 不要添加原图没有的图案、文字、装饰、配件
- 不要改变衣服的颜色和明暗
- 不要加滤镜、边框、水印、文字标注
- 不要拉伸、压缩、变形
```

**英文版**（Nano Banana / ChatGPT / Midjourney 更稳）：

```text
Task: turn this casual phone photo of a garment into a clean e-commerce product shot.

Preserve exactly: silhouette, fit, length, width, color, hue, saturation,
all prints, graphics, text, logos, embroidery, buttons, zippers, pockets,
drawstrings, tags, stitching, seams, and fabric texture.

Requirements:
- View: straight-on front view, camera at the garment's center height,
  no perspective distortion, no tilt.
- Form: laid flat or hanging naturally, smooth surface, no occlusion,
  no bunched fabric.
- Background: pure white (#FFFFFF), clean and even.
- Lighting: soft, even studio light, no blown highlights, no hard shadows.
- Framing: the entire garment is visible, about 8% empty margin on all sides,
  perfectly centered horizontally and vertically.

Do not: include people, hands, mannequins, hangers, clips, walls, floors,
furniture, props; add any new prints, text, or decorations; change colors;
apply filters, borders, watermarks, or text overlays; stretch or distort.
```

### 【提示词 2】从正面图推断侧面（慎用）

**什么时候用**：实在没办法拍侧面时。
**风险**：AI 会猜。纯色、无图案的衣服成功率高；有印花、logo、拼接的衣服容易出错。

```text
【任务】
参考这张衣服的正面图，生成同一件衣服的「严格正侧面图」。

【视角要求】
- 相机绕到衣服的正侧方，与正面图成 90 度，同一高度
- 必须是严格的 90 度正侧面，不要 45 度斜侧视角
- 画面中只看到衣服的侧面轮廓：袖子侧边、衣身厚度、侧缝线、
  下摆的侧面弧度
- 袖子的形态与正面图一致（短袖就是短袖，长袖就是长袖）

【必须保持一致】
- 颜色、面料纹理、厚度感
- 领口的形状与高度
- 下摆的长度与弧度
- 纽扣/拉链的位置（侧视图里能看到的部分）

【必须做到】
- 背景：纯白色（#FFFFFF）
- 光线：与正面图相同的柔和摄影棚光
- 构图：衣服完整入画，居中，占画面高度约 80%

【绝对禁止】
- 不要出现人、模特、衣架、道具
- 不要添加正面图里没有的图案或装饰
- 不要改变衣服的版型和长度
- 不要生成透视图、剖面图、爆炸图
```

**英文版**：

```text
Task: using this front view of a garment, generate the SAME garment in a
strict 90-degree side profile view.

View: camera moved exactly 90 degrees to the side, same height as the front
view. Strict 90° profile, not a 45° three-quarter view. Only the side
silhouette is visible: the side of the sleeves, the body thickness, the side
seam, the side curve of the hem. Sleeve length must match the front view.

Consistency: same color, same fabric texture, same perceived thickness, same
collar shape, same hem length and curve, visible buttons/zippers in the same
positions.

Requirements: pure white background (#FFFFFF), same soft studio lighting as
the front view, garment fully in frame and centered, occupying about 80% of
the image height.

Do not: include people, mannequins, hangers, props; add prints or decorations
not present in the front view; change the silhouette or length; produce
perspective, cutaway, or exploded views.
```

### 【提示词 3】从正面图推断背面（不推荐）

> **强烈建议直接拍背面。** 背面有图案、文字、拼接设计时，AI 生成的基本都是错的。
> 下面这个只在「背面是纯色」时勉强可用。

```text
【任务】
参考这张正面图，生成同一件衣服的「正背面图」。

【视角要求】
- 相机绕到衣服正后方 180 度，同一高度
- 严格正对背面，无透视变形

【一致性要求】
- 领口、肩线、袖口、下摆的形状与正面完全一致
- 颜色、面料、厚度一致
- 如果正面有图案，背面默认保持纯色，不要复制正面的图案到背面
- 如果没有把握背面长什么样，就保持简洁纯色，不要编造设计

【必须做到】
- 纯白色背景
- 与正面图相同的光线
- 衣服完整入画、居中

【绝对禁止】
- 不要编造背面图案、文字、标签
- 不要出现人、模特、衣架
- 不要出现吊牌、尺码标（除非正面图里也有）
```

## 三、辅助提示词

### 【提示词 4】把三张图统一成同一画幅

**什么时候用**：三张图的长宽比或衣服大小差太多。
**说明**：衣柜程序会自动裁剪透明边并按高度对齐，但这个提示词能让效果更稳。

```text
【任务】
把这张衣服图放到一个 3:4（1200×1600 像素）的纯白画布上。

要求：
- 衣服保持原始比例，不拉伸、不压缩
- 衣服高度占画布高度的 75%
- 衣服在画布中水平居中、垂直居中
- 衣服完整，四周不裁切
- 背景纯白，无阴影、无投影
- 除画布尺寸外，不改变衣服的任何细节
```

### 【提示词 5】抠图（当工具没有抠图按钮时）

**优先用工具自带的「抠图 / 消除背景」功能**。只有没有这个功能时，才用提示词：

```text
【任务】
去掉背景，只保留衣服本身，输出透明背景的 PNG。

要求：
- 完整保留衣服的全部边缘细节，包括：薄纱、蕾丝、毛边、流苏、
  拉链齿、纽扣边缘、刺绣凸起
- 不要残留任何背景像素
- 衣服边缘不要有白色描边或毛边
- 不要改变衣服本身的颜色、亮度、透明度
- 衣服内部的镂空（比如袖口的空隙）必须是真透明，不能填白
```

### 【提示词 6】增强立体质感（可选，有风险）

**什么时候用**：衣服拍得很平，想要一点「3D 商品渲染」的立体感。
**风险**：容易顺手改掉图案，**只能在纯色衣服上用**。

```text
【任务】
在不改变衣服款式、颜色、图案、版型的前提下，增强这张商品图的立体感。

要求：
- 补充真实的面料纹理：棉质要有织纹，针织要有线圈，牛仔要有斜纹
- 增加自然、细微的褶皱和起伏，让衣服看起来有体积，而不是一张纸
- 加入柔和的环境光遮蔽（褶皱凹陷处稍暗），增强厚度感
- 保持纯白背景
- 不要添加落在地上的投影
- 整体仍然是商品图风格，不要做成 3D 渲染图或插画

【禁止】
- 改变任何图案、文字、logo 的位置和内容
- 大幅改变褶皱分布
- 把衣服做得像塑料或皮革（除非本来就是）
```

## 五、每件衣服的填写模板

复制这段，把变量换成你衣服的实际情况，接在【提示词 1】后面：

```text
【本件衣服的具体信息】
- 类型：<T恤 / 衬衫 / 卫衣 / 针织衫 / 外套 / 长裤 / 半身裙 / 连衣裙 / 鞋 / 包>
- 主色：<黑色 / 白色 / 米色 / 牛仔蓝 / …>
- 图案：<纯色 / 条纹 / 格纹 / 印花 / 字母 / 拼接 / 无>
- 面料：<棉 / 针织 / 牛仔 / 雪纺 / 羊毛 / 皮革 / …>
- 特殊细节：<落肩 / 开衩 / 收腰 / 荷叶边 / 金属拉链 / …>

【以上信息仅用于约束生成结果，画面中不要出现任何文字说明】
```

## 六、生成完的检查清单

每张图都对照检查，**任何一项不通过就重新生成**：

- [ ] 颜色和原图一致（把两张图并排对比）
- [ ] 图案、文字、logo 的位置和内容没变
- [ ] 纽扣、拉链、口袋数量没变
- [ ] 没有多余的人、手、衣架、道具
- [ ] 背景是干净的纯白
- [ ] 衣服完整，没有被切掉一部分
- [ ] 三张图的衣服大小看起来差不多
- [ ] 三张图的光线方向一致（不要一张左亮一张右亮）

## 七、常见失败与修正

| 问题 | 原因 | 怎么改 |
|------|------|--------|
| 图案被改得乱七八糟 | 图像模型倾向于「重绘」 | 在提示词里加重：「图案必须逐像素保持原样，不要重绘」；或者只让 AI 去背景，不重绘 |
| 生成了模特穿着 | 模型默认服装图是上身图 | 负向提示词加「人、模特、人体」；正向强调「平铺、垂挂、无人体」 |
| 背景还有淡灰色阴影 | 模型保留了投影 | 强调「无影子、无投影、背景纯白 #FFFFFF」；后期用抠图工具处理更快 |
| 三张图衣服大小不一样 | 每次生成构图随机 | 用【提示词 4】统一画幅；或交给程序自动对齐 |
| 侧面图变成了 45° 斜侧 | 模型对「侧面」理解含糊 | 强调「严格 90 度」「相机与正面成直角」 |
| 背面多出图案 | AI 自行脑补 | 直接放弃 AI，实拍背面 |
| 衣服被拉长/变宽 | 模型改了版型 | 提示词加「保持原始宽高比，不拉伸」；优先重新生成 |

## 八、工具使用建议

### 即梦 / 可灵 / 豆包 / 通义（国内，网页版，有免费额度）

1. 进入「图片编辑 / 图生图」，上传你的原图
2. 粘贴【提示词 1】，先只做「整理成白底商品图」这一件事
3. **一次只让它改一件事**，不要一次提十个要求
4. 生成后直接使用平台自带的「抠图 / 智能抠图」导出透明 PNG
5. 不满意就在同一会话里说「保持图案不变，只把背景换成纯白」

### Nano Banana（Gemini）/ ChatGPT

- 英文提示词效果更稳，直接用上面的英文版
- 它们擅长「编辑」而不是「重画」，保真度通常更高
- 上传原图后，一次只下一个指令

### 通用原则

- **一次一个改动**：先整理背景，再统一画幅，最后抠图
- **保留原图**：永远留着手机原片，任何一步不满意都能重来
- **宁可重拍，不要硬修**：侧面和背面拍一次只要 30 秒，比修图快得多

## 九、一句话总结

> **AI 帮你把照片变干净，不帮你把衣服变出来。**
> 正面、侧面、背面都自己拍，AI 只做「整理 + 抠图」，
> 这样导进衣柜的图才是你真实的那件衣服。
