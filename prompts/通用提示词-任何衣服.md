# 通用提示词 · 任何衣服 · 皮克斯风

> 不写死任何款式，上传什么衣服就生成什么衣服。
> 四个代码块都可以整段直接复制，不需要修改。
> 2026-11-18

---

## 使用顺序

```
① 正面（提示词 1）→ 满意后保存
② 侧面（提示词 2，把正面图一起上传）
③ 背面（提示词 3，把正面图一起上传）
④ 模特（提示词 4，上传自己的全身照）
⑤ 用平台自带的「抠图」导出透明 PNG
```

## 提示词 1 · 任意单品的正面

```text
【任务】
参考我上传的图片，把图中的这件服装单品重新绘制成 3D 皮克斯动画风格的独立单品图。

【风格】
3D 皮克斯动画电影风格，Pixar / Disney 质感，圆润柔和的造型，
卡通渲染，非照片写实，细腻但简化的布料褶皱，柔和次表面散射，
电影级柔光，纯白色背景（#FFFFFF），无投影

【必须保留这件单品的全部特征】
- 先判断它是什么：上衣、外套、裤装、裙装、连衣裙、鞋、包，还是配饰
- 版型、长短、宽窄、整体轮廓
- 主色与所有配色，不要偏色
- 所有图案、印花、文字、logo、刺绣，位置和内容保持不变
- 所有结构细节：领口、袖型、口袋、拉链、纽扣、抽绳、腰带、肩带、鞋带、五金件
- 面料的大致质感（棉、针织、牛仔、皮革、羽绒等），但用卡通方式简化表现
- 生成前先在心里清点：几个口袋、几颗纽扣、几条拉链、什么领口，生成结果必须与参考图一致

【从人到单品】
- 如果图里有人穿着这件单品，请把它单独提取出来
- 恢复成平铺或自然展开的完整单品形态，不穿在任何人身上
- 被身体、手臂或手机遮挡的部分，按对称性和款式合理补全
- 穿着产生的过度褶皱，恢复成自然平整的状态

【画面要求】
- 正面视角，镜头与单品中心等高，无透视变形
- 纯白色背景 #FFFFFF，无渐变、无地面、无投影
- 柔和均匀的棚拍光，光源在左上方
- 单品完整入画，水平垂直居中，占画面高度约 75%
- 用卡通风格表现：柔和的块面高光和阴影，不要真实布料纹理

【必须去掉】
人物、脸、手、腿、身体、头发、手机、镜子、房间、床、沙发、衣柜、衣架、夹子

【不要】
- 不要照片写实风格
- 不要真实布料纹理、毛孔级细节
- 不要改变款式、颜色、图案、结构细节
- 不要添加原图没有的图案、文字、装饰
- 不要改变单品的比例和长短
- 不要阴影、投影、文字标注、水印、边框
```

## 提示词 2 · 任意单品的严格侧面

**上传提示词 1 生成的正面图，再粘贴这段。**

```text
【任务】
参考这张 3D 皮克斯动画风格的单品图，生成同一件单品的严格 90 度正侧面图。

【必须完全一致】
- 单品的类别、款式、版型、长短
- 主色与所有配色
- 图案、文字、logo 的内容与位置
- 画风、卡通渲染质感
- 光照方向与背景

【视角，根据单品类型自动适配】
- 上衣 / 外套：看到袖子侧边、衣身厚度、侧缝线
- 裤装：看到裤腿侧面轮廓、裤腰和裤脚
- 裙装 / 连衣裙：看到裙摆的侧面弧度和厚度
- 鞋：看到鞋的完整侧面剪影，包括鞋头和鞋跟
- 包：看到包的侧面厚度、提手和肩带
- 配饰：看到它的侧面结构与厚度

【相机位置】
- 绕到单品正侧方，与正面图成 90 度，同一高度
- 必须是严格的正侧面，不要 45 度斜侧视角
- 侧面要表现出真实的厚度，不要压扁成一张纸
- 有拉链、纽扣、肩带的一侧，按参考图如实表现

【画面】
- 纯白色背景 #FFFFFF，无渐变、无投影
- 单品完整居中，高度与正面图一致，约占画面高度 75%
- 卡通渲染，非照片写实

【不要】
- 不要出现人、模特、衣架、道具
- 不要添加正面图里没有的图案或装饰
- 不要改变单品的款型和长度
- 不要透视变形、透视图、剖面图
- 不要阴影、文字、水印
```

## 提示词 3 · 任意单品的背面

**上传提示词 1 生成的正面图，再粘贴这段。**

```text
【任务】
参考这张 3D 皮克斯动画风格的单品图，生成同一件单品的正背面图。

【必须完全一致】
- 单品的类别、款式、版型、长短
- 主色与所有配色
- 画风、卡通渲染质感
- 光照方向与背景
- 肩线、领口、袖口、下摆、裤脚、鞋跟等边缘形状

【视角，根据单品类型自动适配】
- 上衣 / 外套：看到背部肩线、后背拼接、下摆
- 裤装：看到臀部与后口袋、裤腿背面
- 裙装 / 连衣裙：看到背部拉链或开衩、裙摆背面
- 鞋：看到鞋跟与后跟细节
- 包：看到背面结构与肩带连接处
- 配饰：看到背面结构

【背面设计规则】
- 如果参考图能看到背面的一部分，严格以那一部分为准
- 如果背面是纯色，就保持纯色，不要把正面图案复制到背面
- 拿不准背面长什么样时，选择最简洁的合理方案，不要编造复杂设计

【画面】
- 纯白色背景 #FFFFFF，无渐变、无投影
- 单品完整居中，高度与正面图一致，约占画面高度 75%
- 卡通渲染，非照片写实

【不要】
- 不要编造背面图案、文字、标签、吊牌、尺码标
- 不要出现人、模特、衣架
- 不要阴影、投影、文字、水印
```

## 提示词 4 · 皮克斯虚拟形象

**上传你的正面全身照，再粘贴这段。**

```text
【任务】
参考我上传的全身照片，生成我的 3D 皮克斯动画风格虚拟形象，用于虚拟试衣。

【风格】
3D 皮克斯动画电影风格，Pixar / Disney 质感，圆润柔和的造型，
卡通渲染，非照片写实，柔和次表面散射，电影级柔光，
纯白色背景（#FFFFFF），无投影

【保留我的特征】
- 脸型、五官比例、肤色
- 发型、发色、发长
- 平时佩戴的眼镜等物件
- 身形比例和大致身高

【姿态】
- 正面自然站立，面朝镜头
- 双臂自然下垂，与身体保持明显空隙（至少一个拳头宽），不要贴住身体
- 双腿并拢或自然分开，双脚完整露出
- 不要摆姿势、不要道具

【服装要求（重要）】
- 只穿最简单的浅色贴身打底：白色吊带或白色短袖 + 浅灰色紧身短裤
- 赤脚，不穿鞋、不穿袜子
- 不要帽子、围巾、首饰、包包

【画面】
- 全身完整入画：头顶到脚底
- 头顶留约 5% 空白，脚底留约 5% 空白
- 纯白色背景 #FFFFFF，无渐变、无地面、无投影
- 柔和均匀的光照，与衣物单品图一致
- 人物居中，约占画面高度 90%

【不要】
- 照片写实、真人质感、皮肤毛孔
- 运动鞋、鞋子、袜子
- 地板阴影、渐变背景
- 复杂服装、图案、配饰
- 侧身、走姿、夸张表情
```

## 两条使用提示

1. **白色或米色的衣服**：把提示词里的 `纯白色背景 #FFFFFF` 换成 `浅灰色背景 #D9D9D9`，抠图时衣服边缘更清楚。
2. **一次只改一件事**：正面不满意就重生成正面，不要同时改风格、背景和姿态。侧面和背面一定基于满意的正面图生成。

## 检查清单

- [ ] 是卡通 / 皮克斯感，不是照片
- [ ] 背景是纯色，没有渐变和阴影
- [ ] 颜色和原图一致
- [ ] 口袋、纽扣、拉链、图案的数量和位置没变
- [ ] 正面、侧面、背面三张大小接近
- [ ] 没有人、手、手机、衣架、房间
- [ ] 最后导出的是透明背景 PNG
